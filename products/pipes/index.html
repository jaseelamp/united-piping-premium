Technical examples

  • Carbon steel seamless pipes: 1/2"–24"
  • Carbon steel welded pipes: 2"–120"
  • Line pipe grades include API 5L B, X42, X52, X60, X65, X70, and X80.
  • Referenced material specifications include ASTM A106, ASTM A53, ASTM A333, ASTM A671, ASTM A672, and API 5L.
  • Stainless steel grades include 304/304L, 316/316L, 321, 347, and 904/904L.
  • Duplex material references include UNS S31803, S32205, and S32750/S32760.
